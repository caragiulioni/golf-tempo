# Swing Sync handoff for Kiro
All files are plain text (SVG, CSS, HTML, MD) except PNG icons.
- tokens.css: colors/fonts, dark + light via data-theme
- main-screen.html: working responsive main screen (open in browser; theme toggle works)
- design-spec.md: layout, breakpoints, rules
- logo/: mark + lockup SVGs (dark/light/mono), favicon.svg, palette.json, PNG app icons
Start by reading design-spec.md, then main-screen.html. SHORT presets list is a TODO (see design-brief.md).
