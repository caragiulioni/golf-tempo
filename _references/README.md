# _references

**Planning equivalent: the site survey and background studies.**

This folder holds the raw material the project started from. Nothing here is built or changed. It is evidence we look back at.

## What's in it

- `INIT golf tempo.md`: the original project description. It states the goals, the technology and the phases.
- `VID_20261107_135008.mp4`: a screen recording of the Tour Tempo app. We measured its audio to learn how its beats are timed.
- `Screenshot ...` images: frames from that recording, showing Tour Tempo's presets and controls.
- `layout-DARKMODE.png` and `layout-LIGHTMODE.png`: the layout and color mockups for our own app.

## Why it matters

When a question comes up, such as "how does Tour Tempo actually sound?", the answer comes from here, not from memory. Good planning rests on evidence, and this is where the evidence lives.

## How to use it

- Add new material whenever you have it: recordings, screenshots, notes, sketches.
- Don't edit existing files. If the original is wrong, write the correction somewhere else and say why.
- Give files clear names so you can tell what they are later.
