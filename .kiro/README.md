# .kiro

**Planning equivalent: the planning office.**

This folder is where Kiro, the AI assistant, gets its instructions. Everything in it is written for Kiro to read, but it is plain text and meant for you to read and edit too.

## What's in it

- `steering/`: standing rules. Kiro reads these at the start of its work.
- `specs/`: the detailed plan for each feature.

## Why it matters

Kiro starts every conversation knowing only what is written down. This folder is its memory of the project. If a decision isn't recorded here, Kiro may not know about it. To change how Kiro works on this project, change the files here.

The folder name starts with a dot, so your file browser may hide it. In Kiro it shows up in the file list.
