# components

**Planning equivalent: the standard parts catalogue.**

Reusable building blocks: segmented controls, preset buttons, section labels, the tempo badge, playback controls, the beat timeline, the confirmation dialog.

## Rules

- Look here before building any new piece of interface. Reuse a part if it fits, extend it with an option if it nearly fits, and create a new one only if nothing does.
- Each component reads its colors and spacing from `theme/`.
- If the same element or style shows up twice, it belongs here.

Currently empty. Parts are added as the specs that need them are built.
